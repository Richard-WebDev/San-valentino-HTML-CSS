# Buon San Valentino — Biglietto animato

Semplice biglietto di auguri di San Valentino realizzato con **HTML e CSS puri**, senza framework né librerie esterne.

Progetto personale nato come esercitazione.

---

## Tecnologie

- **HTML5** — struttura semantica, attributi `alt`, favicon
- **CSS3** — Flexbox, sovrapposizione di livelli, design responsive
- **Google Fonts** — Dancing Script

Nessuna dipendenza da installare.

---

## Struttura

```
index.html      struttura principale
css/            foglio di stile
img/            sfondo e favicon
gift-img/       animazione decorativa
```

---

## Come visualizzarlo

Scarica il repository e apri `index.html` in un qualsiasi browser.

```
git clone https://github.com/Richard-WebDev/San-valentino-HTML-CSS.git
cd San-valentino-HTML-CSS
```
